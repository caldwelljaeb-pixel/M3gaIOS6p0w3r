# M3gaEmojiVault 0.1.1

A classic-era emoji browser for jailbroken iOS 6 devices.

## Features
- Browse a grid of classic iOS emoji.
- Search by emoji character, name, or category.
- Tap an emoji to copy it immediately.
- Press and hold an emoji to open a small action menu with **Copy** and **Cancel**, similar to iFile's item actions.
- Visible creator credit: **made with ❤️ by M3gaIOS6p0w3r**.

The 0.1.1 build targets iOS 6.0 and ARMv7. Its Settings entry is provided through PreferenceLoader and includes switches for emoji names and creator credit. It uses the system emoji font and the iOS pasteboard, so copied characters can be pasted into other apps that support them.
