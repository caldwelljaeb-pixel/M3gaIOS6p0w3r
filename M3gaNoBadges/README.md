# M3gaNoBadges 0.1.1

A classic-iOS tweak that hides red notification badges on Home Screen app icons.

- One Settings switch: Hide Badges.
- Does not clear notifications or modify stored badge counts.
- Turning the switch off restores normal badge display.
- Uses the iOS 6 SpringBoard badge-visibility delegate.
- Target: iOS 6.0+ on ARMv7.
